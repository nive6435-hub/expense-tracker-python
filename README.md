# Python Expense Tracker

A beginner-friendly Python project designed to record, manage and track daily expenses.

## Features
- Add new expenses
- Record expense dates
- Categorize expenses
- View expense history
- Calculate total expenses
- Save expense records using JSON

## Technologies Used
- Python
- JSON
- VS Code

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

```bash
python expense_tracker.py
```

## Learning Outcomes
- Python functions
- Lists and dictionaries
- File handling
- JSON data storage
- Basic programming logic
